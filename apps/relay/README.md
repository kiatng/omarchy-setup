# Relay

Live translated meeting captions for Omarchy. Optional in the root setup installer (`--relay`). Source uses Qt Quick and the system keyring; no provider keys, recordings, transcripts, or model weights are bundled.

Use `bin/build` and `bin/test` in this directory. Configure the microphone and provider in the app on the destination computer; cloud providers receive captured audio when enabled. Install an offline provider separately if desired.
